# Ray maps (P045)

Generated by `scripts/ray_map_overlays.py` (frames nearest 2022-04-01 12:00 UTC).

Ray map per docs/contract.md: 512 x 512 input, 16 px patches, channels = unit direction in the Sun-aligned frame (x toward the Sun's azimuth, z up) + valid flag. Validity = calibrated camera, >= 50 % of the patch footprint inside the camera mask, elevation >= the near-horizon floor (`configs/near_horizon.csv`). Poses from `configs/camera_poses.yaml` (P044).
